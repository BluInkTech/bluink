# @bluink/typst

The pinned Typst engine for Bluink PDF generation, packaged for Linux x64,
Windows x64 and macOS arm64. The resolver selects the installed executable
without relying on the system PATH. No installation scripts or first-use
downloads are required.

Bluink-owned packaging code is MPL-2.0. Typst retains Apache-2.0; its upstream
notices and embedded-asset notices accompany the package.

For product information, visit [bluink.app](https://bluink.app).
